# MZB-data

Compatible with Python 3.14. Scripts for flow cytometry and CyTOF data from panels for hierarchical gating of marginal zone B-cells.

# preprocessing
- Preprocessing functions for merging microarrays.
- Function for scraping donors from liquid nitrogen spreadsheet to search for donors with specific tissue and age parameters.

# scripts
- Scripts for clustering and visualization of CyTOF and flow cytometry data for B cell subsets.
- Script for clustering and visualization of scRNA-seq data for CZI dataset.

# src
- Python modules for importing FCS data into the environment and preparing it as an AnnData object.
